# 预测页面多维概览功能说明

## 🎯 功能概述

在预测页面（ForecastPage）新增了**多维概览视图**，提供6种专业的高级可视化图表，用于全方位展示2019年预测数据与实际数据的对比分析。

## 📊 可视化组件说明

### 1. 🌐 3D时空演变曲面图
- **技术**：ECharts GL 3D散点图，支持自动旋转
- **维度**：
  - X轴：城市索引（空间维度）
  - Y轴：时间维度
  - Z轴：污染物浓度
- **功能**：
  - 切换指标（PM2.5 / PM10 / AQI）
  - 自动旋转展示
  - 颜色映射浓度等级
- **用途**：立体展示时空演变规律

### 2. 🎯 多污染物雷达对比图
- **技术**：ECharts 雷达图
- **维度**：6种污染物（PM2.5, PM10, SO₂, NO₂, CO, O₃）
- **功能**：
  - 预测值（蓝色）vs 实际值（橙色）
  - 归一化显示（0-100）
  - 面积覆盖展示差异
- **用途**：多维度整体对比，一目了然

### 3. 🔥 污染物关联热力图
- **技术**：ECharts 热力图
- **维度**：污染物间相关系数矩阵
- **功能**：
  - 切换预测/实际数据
  - Pearson相关系数计算
  - 颜色映射相关强度（-1到+1）
- **用途**：揭示污染物联动关系

### 4. 📊 AQI等级分布统计
- **技术**：ECharts 柱状图
- **维度**：6个AQI等级（优/良/轻度/中度/重度/严重）
- **功能**：
  - 预测vs实际等级分布对比
  - 自动计算AQI值
  - 等级一致性分析
- **用途**：预测准确度评估

### 5. 📈 多维平行坐标系
- **技术**：ECharts 平行坐标
- **维度**：6种污染物 + AQI（7维数据）
- **功能**：
  - 拖拽坐标轴筛选数据
  - 颜色映射AQI等级
  - 显示/隐藏异常值
  - 采样200条数据避免卡顿
- **用途**：高维数据全景视图，模式发现

### 6. 📦 预测误差分布箱线图
- **技术**：ECharts 箱线图
- **维度**：各污染物的误差统计
- **功能**：
  - 显示最小值、Q1、中位数、Q3、最大值
  - 误差绝对值统计
  - 异常值识别
- **用途**：模型性能评估，误差分析

## 🎨 设计特点

### 专业性
- 使用ECharts GL实现3D可视化
- 多种高级图表类型（雷达、热力、平行坐标、箱线图）
- 科学的配色方案和视觉映射

### 交互性
- 图表自动旋转、缩放
- 坐标轴拖拽筛选
- 模式切换（预测/实际）
- 指标切换

### 响应式
- 响应窗口大小变化
- 移动端自适应布局
- Grid布局自动调整

### 性能优化
- 数据采样（平行坐标限制200条）
- 3D场景限制数据量（300个点）
- 按需渲染，避免卡顿

## 🔄 使用流程

1. **切换视图模式**
   - 点击工具栏"📊 多维概览"按钮进入概览模式
   - 点击"🔍 详细分析"返回原有详细视图

2. **选择地区**
   - 使用地区下拉框筛选
   - 所有图表联动更新

3. **时间选择**
   - 使用时间点下拉框
   - 概览展示该时间点的数据

4. **交互探索**
   - 3D图表：鼠标拖拽旋转、滚轮缩放
   - 热力图：切换预测/实际模式
   - 平行坐标：拖拽坐标轴筛选
   - 所有图表支持tooltip悬浮提示

## 💡 技术实现

### 核心依赖
```json
{
  "echarts": "^5.5.0",
  "echarts-gl": "^2.0.9"  // 3D图表支持
}
```

### 组件结构
- `ForecastOverview.vue` - 概览组件（新增）
- `ForecastPage.vue` - 主页面（集成概览）

### 数据流
```
ForecastPage
  ├─ actualCache (实际数据缓存)
  ├─ predCache (预测数据缓存)
  └─ ForecastOverview
       ├─ allActualData (计算属性：所有实际数据)
       ├─ allPredData (计算属性：所有预测数据)
       └─ 6个图表实例
```

### 计算逻辑
- **AQI计算**：基于6种污染物的分段函数
- **相关系数**：Pearson相关系数算法
- **误差统计**：箱线图五数概括法
- **归一化**：按最大值归一化到0-100

## 🎓 使用建议

### 数据探索顺序
1. **整体把握**：先看雷达图了解多维度整体情况
2. **时空规律**：观察3D曲面图的时空分布
3. **关联分析**：通过热力图理解污染物相关性
4. **等级评估**：AQI分布图评估预测准确度
5. **深入探索**：平行坐标发现特殊模式
6. **误差分析**：箱线图定位预测薄弱环节

### 最佳实践
- 概览用于发现问题，详细分析用于深入研究
- 结合地区筛选和时间选择，进行对比分析
- 关注异常值和离群点，可能揭示特殊事件
- 利用平行坐标的筛选功能，聚焦特定数据子集

## 📝 注意事项

1. **性能**：大数据量时自动采样，避免浏览器卡顿
2. **兼容性**：需要现代浏览器支持WebGL（3D图表）
3. **数据质量**：确保预测数据完整，否则部分图表可能显示异常
4. **移动端**：触摸操作支持3D旋转，但体验不如桌面端
